# FinalProject_2026_CTierney: code and data

CSC 8840 Final Project (Option 2), Carter Tierney. A system dynamics model of data center development in Coweta County, Georgia, built in the NetLogo 7 System Dynamics Modeler.

## Contents

- `model/DataCenterSD.nlogox`: the NetLogo 7.0.4 model (interface, SD stock-and-flow diagram, Info tab). Generated by `model/build_nlogox.py`; do not edit by hand.
- `data/parameters.csv`: every constant (value, unit, source or ASSUMPTION, low/high range). `data/sources.md`: sources (S1-S24).
- `notes/model_spec.md`: the equations. `notes/demo_script.md`: the two demo configurations.
- `experiments/E*.xml`: BehaviorSpace setups for E0-E10. `experiments/E*_results.csv`: their outputs. `experiments/findings.md`, `validation_log.md`, `thresholds.csv`, `sensitivity_*.csv`: analysis results.
- `analysis/`: Python scripts (reference model, tests, validation, sensitivity, experiments, findings, figures, snapshots).
- `figures/`: all figures. `report/build_report.py`, `slides/build_slides.py`: build the report and slides from the CSVs.

## 1. Open and run the model (no Python needed)

- Install NetLogo 7.0.4 (https://ccl.northwestern.edu/netlogo/) and open `model/DataCenterSD.nlogox` (File > Open).
- On first launch NetLogo 7 may ask about sending anonymous usage data; either answer is fine.
- Choose scenario controls on the left (or press a preset button: Sail only, Sail + Bridgeport + Pegasus, + Peach), press **setup**, then **go**. The run stops at year 20.
- Tools > System Dynamics Modeler shows the stock-and-flow diagram.

## 2. Rerun BehaviorSpace experiments

- In the GUI: Tools > BehaviorSpace > Import, choose e.g. `experiments/E5.xml`, then Run.
- Headless from Python (Python 3 with pandas, numpy, scipy, matplotlib), from this folder:
  - Set `NETLOGO_HOME` to the NetLogo install folder **without spaces in its path** (the shipped `netlogo-headless.bat` breaks on spaces; `analysis/nl.py` calls Java directly and needs Java 17+ on PATH). Example in PowerShell: `$env:NETLOGO_HOME = "C:\dev\nl704"`.
  - `python analysis/run_experiments.py E1` (or no argument for all of E0-E10; about 3 minutes).
  - `python analysis/compare_models.py` checks NetLogo against the Python reference model (prints PASS).

## 3. Regenerate the analysis and figures

- `python analysis/test_reference.py` (6 tests of the reference model)
- `python analysis/validate.py`, `python analysis/compare_counties.py`, `python analysis/sensitivity.py`, `python analysis/gate.py` (validation, Step 5)
- `python analysis/findings.py` (summaries, thresholds, `experiments/findings.md`)
- `python analysis/make_figures.py` (every results figure in `figures/` from the CSVs)
- `python analysis/make_diagrams.py` (causal loop and stock-and-flow diagrams; needs Graphviz `dot`)
- `python analysis/snapshots.py` (NetLogo GUI snapshots; needs a desktop session and a JDK)
- `python model/build_nlogox.py` (regenerate the NetLogo model from the spec and `parameters.csv`)
